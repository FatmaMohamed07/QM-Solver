# QM-Solver

An interactive web application for simplifying Boolean functions using the Quine-McCluskey algorithm.

## Features

- Supports SOP (Sum of Products) and POS (Product of Sums)
- Supports 1 to 10 variables
- Handles Don't Care conditions
- Shows the solution step by step using the Tabular Method
- Generates a Prime Implicant Chart
- Provides K-Map visualization for 2 to 5 variables
- Verifies the optimized result using a Truth Table
- Supports Dark and Light Mode
- Copy the final Boolean expression
- Print results or save them as PDF

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Select the form type: SOP or POS.
2. Enter the number of variables.
3. Enter the primary terms (Minterms or Maxterms).
4. Optionally enter Don't Care terms.
5. Click **Run Tabular Method & K-Map**.
6. View the step-by-step solution and the optimized Boolean expression.

## About the Algorithm

The Quine-McCluskey algorithm is a tabular method used to simplify Boolean functions and find an optimized Boolean expression.
